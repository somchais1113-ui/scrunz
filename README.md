# SC Running Performance Engine V2

Open `index.html` in a modern browser. No server or external JavaScript library is required.

## Included
- Command Center: Where am I? / Why? / What next?
- SC Fitness / Fatigue / Form (estimated EWMA model)
- SC Load Focus and 7D/28D load ratio
- Aerobic efficiency and threshold trend
- Workout prescription vs execution compliance
- Race estimates with confidence labels
- Pace-normalized mechanics views
- Garmin recovery signal panel and Health Snapshot trend
- 12-layer Analysis Plan
- Garmin Activities CSV import

## Data trust
Garmin-native activity metrics come from `data/Activities_latest.csv`. HRV Status, Acute Load, Heat Acclimation and VO2 Max are based on the screenshots supplied in the conversation. SC metrics are clearly labelled as estimates/proxies.

## Important
The dashboard is a coaching/analytics aid, not a medical diagnostic tool. It intentionally shows NEEDS DATA instead of inventing recovery or readiness values.
