# SC Metrics Methodology

- **SC Activity Load** = duration_minutes × Aerobic Training Effect / 3.
- **SC Fitness** = 42-day EWMA of daily SC Activity Load.
- **SC Fatigue** = 7-day EWMA of daily SC Activity Load.
- **SC Form** = Fitness − Fatigue.
- **SC Load Ratio** = 7-day load / (28-day load / 4).
- **SC Efficiency** = speed in metres/minute / average heart rate; used only as a within-athlete trend proxy.
- **SC Load Focus** is a proxy classification using workout title, distance, pace and average HR. It is not Garmin Load Focus.
- **SC Race Estimate** uses a Riegel-style exponent of 1.06 from recent suitable-distance efforts and reports confidence based on source-distance proximity. It is not Garmin Race Predictor or Strava Performance Prediction.
- **Aerobic Decoupling** is intentionally unavailable until lap/stream/FIT data is supplied.
- **Recovery/Readiness** is not fabricated. Daily HRV, sleep and resting HR would be required for a proper readiness engine.
